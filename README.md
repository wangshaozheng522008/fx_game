# 函数射线 / FX GAME

小红书小工具格式的像素风 H5 小游戏：玩家站在坐标原点，怪物出现在平面随机点，15 秒内从 3 个函数里选出能穿过怪物的那一条，沿函数图像发射攻击射线。命中允许 5% 数值偏差。

项目由公开脚手架 [`create-xhs-minitool`](https://github.com/wenyuanw/xhs-minitool) 创建，产物可打包成离线 zip 上传小红书创作服务平台。

## 能力判定

| 需求 | 可行性 | 实现 |
| --- | --- | --- |
| 2D 坐标系 + 原点角色 | 可直接实现 | Canvas 2D 像素缓冲 |
| 随机怪物坐标 | 可直接实现 | 本地随机生成 |
| 三选一函数 | 可直接实现 | 预置函数族拟合，不用 `eval` |
| 15 秒限时 | 可直接实现 | 主线程计时 |
| 函数射线命中（5% 偏差） | 可直接实现 | `\|f(x)-y\| ≤ 5%·距离` |
| 2D 像素风格 | 可直接实现 | 低分辨率点阵精灵 |
| 小红书小工具离线包 | 可直接实现 | 单入口 H5，资源全部本地 |

## 本地预览

```bash
npm install
npm run dev
```

## 打包上传

```bash
npm run build
npm run validate
```

会生成：

- `xhs-tool/` — 提交目录（根目录就是 `index.html`）
- `fx-game-xhs-tool.zip` — 上传到 [创作服务平台](https://creator.xiaohongshu.com/new/red-app)

## 玩法

1. 角色固定在原点 `(0, 0)`。
2. 怪物刷新后会显示坐标，例如 `(4.00, 2.00)`。
3. 在 15 秒内点选正确函数，例如 `y = 0.50x`。
4. 射线沿函数图像射出；与怪物坐标误差不超过 5% 即命中。
5. 共 3 条命。波数升高后会出现 `x²`、`|x|`、`√x`、`sin(x)` 等函数。

最高分保存在本地 `localStorage`（小工具存储不保证永久保留）。
